# Validator Specification

The **Validator** validates outputs generated by the image processing and animation pipeline.

## Validation Metrics

1. **Image Processing**:
   - Compares the processed output size against target dimensions (e.g. `300x340`).

2. **Dithering & Graph**:
   - Asserts that the total number of extracted particles equals `expected_dots` (14,248).
   - Identifies isolated nodes lacking connection edges in the KNN graph structure.

3. **Motion Blocks**:
   - Verifies that the sum of particle IDs in the intro shimmer groups matches the total particle count.
   - Evaluates drift bands to ensure no particle is skipped.

4. **Logo & Travelers**:
   - Asserts that output files contain the designated point counts.
   - Validates that chronological transition events are ordered properly without overlaps or timestamp conflicts.

5. **SVG Structures**:
   - Parses the output SVG using iterative XML scanning to prevent memory bloat.
   - Matches the total element count against expected dot counts.
